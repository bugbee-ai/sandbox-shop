A tiny Android app.
The whole GitHub ecosystem.

Sandbox Shop is a minimal Kotlin checkout demo wired into everything GitHub offers a mobile team — this page itself is deployed by GitHub Pages from the same repository.

  • ⚙️
    CI on every change
    Lint, unit tests, and an installable APK from every push and pull request.
  • 🚀
    One-command releases
    Push a version tag; a GitHub Release with the APK appears.
  • 🛡️
    Security by default
    CodeQL scans, Dependabot updates, and secret push protection.
  • 👥
    Team workflow built in
    Issue forms, PR templates, code owners, and a protected main branch.
